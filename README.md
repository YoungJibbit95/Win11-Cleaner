# Win11-Cleaner
A simple, fast cleaner for saving storage on windows using python

#How to use

1. Download the v1.zip (or current released version) from the Releases tab.
2. Extract it to a folder of your choice.
3. Run "run.bat" to use the script. (some options in the script require you to start "run.bat" as administrator)
4. Choose a option you want to use and enjoy the free storage space by YoungJibbit95´s Win11 Cleaner :D
